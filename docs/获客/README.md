> 更新日期：2026-09-10  
> 用途：拉注册试用，暂不依赖真实支付上线。

## 本目录有什么

| 文件 | 用途 |
|------|------|
| [landing.html](./landing.html) | 单页落地页（可直接浏览器打开或挂到任意静态托管） |
| [演示视频脚本.md](./演示视频脚本.md) | 45～90 秒录屏分镜与旁白 |
| [发帖与短文案.md](./发帖与短文案.md) | V2EX / 即刻 / 社群 / 短视频文案 |

## 使用前改两处占位

1. `landing.html` 里的：
   - `YOUR_WECHAT` → 你的微信号  
   - `YOUR_DOWNLOAD_URL` → 绿色版/安装包下载地址（没有则先改成「私信领取」）  
2. 演示视频：按脚本录控制台真实操作，导出后嵌到落地页或发 B 站。

## 建议投放顺序

1. 录 1 条演示（按脚本）  
2. 落地页填好微信与下载链，本地打开检查  
3. 用「发帖模板」发即刻 / V2EX / 技术群  
4. 私域跟进：是否装上、是否登录、是否加到第 2～3 个项目  

成功标准见 [`../商业化与推广方案.md`](../商业化与推广方案.md)（两周 ≥20 注册）。
