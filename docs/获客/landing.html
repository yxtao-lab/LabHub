常见问题

试用前最常被问到的几句。

会上传我的源码吗？

默认不会。云端保存的是账号、套餐与项目清单元数据；业务代码在你本机的托管目录。

为什么要登录？

登录后才能使用管理功能，并按账号同步清单、计算项目与 AI 额度。

和 Docker / 自己写脚本比呢？

LabHub 面向「多个 Git 工作区」的日常启停与日志入口，不替代容器编排或 CI。

如何获取安装包？
