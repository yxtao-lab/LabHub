# LabHub 演示视频脚本（45～90 秒）

## 目标

让观众 10 秒内看懂：「一个控制台管多个 Git 仓库，能启停、看日志」；片尾给明确行动（下载 / 加微信试用）。

## 成片规格

- 横屏 1920×1080 或 16:9  
- 时长：优先 **60 秒**（短版 45 秒、长版 90 秒）  
- 有旁白或大字幕二选一；开发者向可轻 BGM  

## 分镜（60 秒版）

| 时间 | 画面 | 旁白 / 字幕 |
|------|------|-------------|
| 0–8s | 桌面上一堆终端窗口、多个项目文件夹（可加速） | 「同时维护好几个 Git 项目时，终端和目录很容易乱成一团。」 |
| 8–18s | 打开 LabHub 登录页 → 登录进入 | 「LabHub：本机多仓库控制中枢。」 |
| 18–32s | 侧栏已有 2～3 个项目；点「添加仓库」贴一个 Git 地址（可剪辑跳过克隆等待） | 「粘贴仓库地址，登记到统一清单。」 |
| 32–48s | 点启动 → 状态变「运行中」→ 日志滚动 → 点开运行地址 | 「一键启停，日志和访问地址都在同一个控制台。」 |
| 48–55s | 顶栏：套餐「免费版」、项目 2/3、邀请码一闪 | 「注册即用，免费可管理 3 个项目；清单登录后同步到云端。」 |
| 55–60s | 落地页或大字 CTA | 「搜索 LabHub 试用 / 私信领取安装包。」 |

## 45 秒精简版

砍掉「文件夹乱」开场，直接：登录 → 添加 → 启动看日志 → CTA。

## 90 秒加长版

在 48s 后加 15～20 秒：

- 打开某个项目的「分析总结」页签（有则展示，无则跳过）  
- 或切换「套餐」弹窗，展示免费 / 基础 / 专业三档（**不要强调支付细节**，只说免费 3 个、多了可升级）

## 拍摄注意

1. 用测试账号，手机号可打码。  
2. 不要露出真实 DeepSeek Key、`.env`、客户仓库私密路径。  
3. 克隆太慢就剪掉中间等待，保留「开始克隆 → 已出现在列表」。  
4. 片尾固定一句行动号召，与落地页一致。
